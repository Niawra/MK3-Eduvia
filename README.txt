EDUVIA - HTML CSS JAVASCRIPT

Cara menjalankan:
1. Extract ZIP.
2. Buka folder Eduvia di VS Code.
3. Buka index.html.
4. Jalankan dengan Live Server, atau buka index.html di browser.

Struktur:
index.html = struktur halaman
css/style.css = seluruh desain
js/script.js = interaksi website
assets/ = tempat gambar/aset jika nanti diperlukan
